# PokeVault - Configuration des Produits et Collections

Ce guide vous aide à configurer les collections et produits pour PokeVault.

## 1️⃣ Créer les Collections

Allez dans **Shopify Admin → Products → Collections**

### Collection 1: Protections
- **Title**: Protections
- **Handle**: `protections`
- **Description**: Sleeves premium, toploaders & housses acryliques sur mesure.

### Collection 2: Produits Scellés
- **Title**: Produits Scellés  
- **Handle**: `produits-scelles`
- **Description**: Boosters, ETB, Bundles & Displays. Produits authentiques, scellés d'usine.

## 2️⃣ Importer les Produits

### Via CSV (Recommandé)
1. Allez dans **Shopify Admin → Products → Import**
2. Téléchargez le fichier `pokevault-products.csv`
3. Les produits seront créés automatiquement

### Produits inclus:

**PROTECTIONS:**
- Sleeves Premium Clear 100pcs - €9.99
- Top Loader Rigid 50pcs - €24.99
- Boîte Acrylique pour Booster - €12.99
- Boîte Acrylique pour ETB - €19.99
- Boîte Acrylique pour Display - €34.99

**POKÉMON TCG (Scarlet & Violet):**
- Display Booster Box - €89.99
- Booster Bundle - €29.99
- Booster Single - €4.99

## 3️⃣ Ajouter les Produits aux Collections

Après l'import:
1. Pour chaque produit, ouvrez-le
2. Allez à **Collections**
3. Sélectionnez la collection appropriée (Protections ou Produits Scellés)

## 4️⃣ Images

Les images utilisent des URLs d'images Unsplash publiques. Vous pouvez:
- Garder les images actuelles
- Ajouter vos propres images dans Shopify

## Notes

- Les prix sont en EUR (€)
- Les "Cost" sont des estimations pour la marge
- Tous les produits sont "In Stock"
- Les collections utilisent les bons handles (`protections`, `produits-scelles`) pour les URLs

C'est tout! Après cela, le site est opérationnel. 🚀
