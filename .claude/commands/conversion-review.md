# Audit de conversion d'une page

Analyse une page HTML ou URL fournie et identifie tous les points de friction qui nuisent à la conversion.

## Processus d'audit

### 1. Lis la page complète
Charge le fichier HTML ou la page indiquée.

### 2. Analyse ces 8 dimensions

**Above the fold**
- [ ] Le visiteur comprend-il l'offre en moins de 5 secondes ?
- [ ] Le CTA principal est-il visible sans scroller ?
- [ ] La proposition de valeur est-elle claire et différenciante ?

**Confiance & crédibilité**
- [ ] Y a-t-il des preuves sociales (avis, logos clients, chiffres) ?
- [ ] Les éléments de réassurance sont-ils présents (garanties, certifications) ?
- [ ] L'équipe/l'entreprise est-elle visible ?

**CTAs**
- [ ] Les boutons sont-ils assez visibles (contraste, taille) ?
- [ ] Le texte des CTAs est-il orienté bénéfice ("Démarrer mon projet" > "Envoyer") ?
- [ ] Y a-t-il trop ou trop peu de CTAs ?

**Friction formulaires**
- [ ] Trop de champs demandés ?
- [ ] Les erreurs de validation sont-elles claires ?
- [ ] Y a-t-il un message de réassurance (délai de réponse, confidentialité) ?

**Mobile**
- [ ] La page est-elle vraiment utilisable sur mobile ?
- [ ] Les zones cliquables sont-elles assez grandes (min 44px) ?
- [ ] Le texte est-il lisible sans zoom ?

**Performance perçue**
- [ ] Les images sont-elles optimisées ?
- [ ] Y a-t-il des loaders / skeletons pour les contenus lents ?

**Hiérarchie visuelle**
- [ ] L'œil est-il guidé naturellement vers le CTA ?
- [ ] Y a-t-il trop d'éléments en compétition visuelle ?

**Copywriting**
- [ ] Le texte est-il orienté bénéfice client (pas features) ?
- [ ] Les titres sont-ils accrocheurs ?
- [ ] Y a-t-il un sentiment d'urgence ou de rareté si pertinent ?

### 3. Livrable

**Format de réponse :**
- 🔴 Problèmes critiques (impactent directement la conversion)
- 🟡 Améliorations recommandées (gain significatif)
- 🟢 Points forts à conserver

Pour chaque problème : description + suggestion de fix concrète.
Terminer par un score de conversion estimé /10 et les 3 priorités absolues.
