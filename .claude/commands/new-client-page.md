# Créer une nouvelle page client

Tu es un partenaire créatif de l'agence Helv'Edit. Crée une page HTML complète pour un nouveau client.

## Étapes

1. **Analyse le brief** : Lis le nom du client, son secteur, et ses objectifs depuis le message de l'utilisateur
2. **Lis le design system** : Charge `design-system.css` pour utiliser les bonnes variables
3. **Lis les composants disponibles** dans `components/` pour réutiliser ce qui existe
4. **Propose une direction créative** avant de coder :
   - Palette de couleurs adaptée au secteur
   - Typographie et ambiance (moderne/classique/bold/minimal)
   - Structure des sections (ordre logique pour la conversion)
5. **Code la page** avec ces règles :
   - HTML/CSS/JS vanilla uniquement
   - Importer `design-system.css` en premier
   - Utiliser les variables CSS du design system, ne pas hardcoder des couleurs
   - Ajouter GSAP via CDN pour les animations au scroll
   - Mobile-first, responsive
   - Sections minimum : navbar, hero, services/produits, social proof, CTA final, footer
6. **Qualité** :
   - Jamais de design générique — adapter au secteur du client
   - Toujours penser conversion (CTA clairs, social proof, urgence si pertinent)
   - Animations subtiles (pas d'excès)

## Format de livraison
Un seul fichier `[nom-client].html` auto-suffisant, prêt à ouvrir dans un browser.
